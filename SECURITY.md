# Security

kannada-spell is a spelling dictionary, a command-line tool and Rust libraries that read local text. If you find a security problem in them, such as input that crashes the analyzer or makes it run without end, or a package that installs more than it should, email prasad@luminik.io instead of opening a public issue. Include the commit or release and the steps to reproduce it.

Ordinary bugs and wrong spellings go in [GitHub issues](https://github.com/openkannada/kannada-spell/issues).
